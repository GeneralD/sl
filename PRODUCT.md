# PRODUCT

## Repo

- `GeneralD/sl` — `<repo>` in this skill, bound in Phase 1 and never
  re-derived from a checkout. Every repo-scoped `gh` command carries
  `-R GeneralD/sl`.
- root: `/Users/yumenosuke-k/.local/share/ghq/github.com/GeneralD/sl` —
  `<root>`; every squad, scout and worker brief carries it and every
  `exec` passes it (or a path under it) as `workdir`.
- Public repository, MIT license, default branch `main`, run branch
  `main` (greenfield: worker PRs target `main`).

## Stack

- Swift 6.3.3, SwiftPM package, **Command Line Tools toolchain only**:
  every swift command is invoked as
  `env DEVELOPER_DIR=/Library/Developer/CommandLineTools swift …`
  (Xcode license is unaccepted; `xcodebuild`, `xcrun` tools, XCTest and
  swift-testing are unavailable — never referenced).
- AppKit `NSWindow` overlay; SceneKit `SCNView` behind a `Renderer`
  protocol seam; AVFoundation/NSSound audio;
  `swift-argument-parser` for flags.

## Run

- Build: `scripts/gate` (debug) / `make build` (release).
- Run from checkout: `scripts/run [-- sl-args]` → builds + executes the
  debug binary (pops a real train — this is the product).
- Visual verification: `scripts/shot docs/shots/<name>.png` — launches
  the binary frozen mid-run, captures the screen, kills it. Exactly one
  shot at a time (shot.lock).

## Gate (one command, the same for every issue)

- `scripts/gate` — takes a `.hackathon/gate.<n>.lock` slot, then:
  `swift build` → `slChecks` executable (spec-sentence checks) →
  coverage report + ratchet vs `coverage-baseline.txt` →
  `scripts/arch-graph --check` (stale ARCHITECTURE.md = red) →
  secrets grep scan → no-Xcode/no-sleep lint → binary smoke
  (`sl -v`, `sl --bogus`).

## Tests

- Framework-free: **no XCTest, no swift-testing** (absent from CLT).
  Checks are `[Check]` values living in `Sources/slChecks/`, run by the
  `slChecks` executable via `SLTestKit` (`expect`, `Check`,
  `Tick` fixed-dt clock — never a wall-clock sleep).
- Coverage: `scripts/gate` builds `--enable-code-coverage`, runs
  `slChecks`, reports llvm-cov line % on `Sources/` and fails below
  `coverage-baseline.txt`; exceeding it rewrites the file (ratchet —
  commit the bump with your PR).
- One check per `Interface` item; the check name is a spec sentence
  ("when … returns …").

## Placement rules

| Layer / target | Owns | Never |
|---|---|---|
| `sl` (executable) | argv→`RunSpec`, `NSApplication` lifecycle, watchdog, `--freeze` shot mode | rendering, window internals, flag semantics tables |
| `SLCore` | pure value types: `RunSpec`, flags, trajectory/timing math, config | AppKit, SceneKit, IO, windowing |
| `OverlayKit` | `NSWindow` recipe, screen geometry, display callbacks | scene contents, flags |
| `TrainScene` | `Renderer` protocol + SceneKit impl, scene graph, animation, particles, audio | window creation, argv parsing |
| `SLTestKit` | `Check` DSL, `expect`, `Tick`, pixel-probe helpers | product code |
| `slChecks` (executable) | check registry + runner `main` | product code |

Enforced by: SPM target boundaries in `Package.swift` (a wrong import
fails to compile) + `scripts/arch-graph` renders the target graph into
`docs/ARCHITECTURE.md` and the gate fails when the doc is stale.

## Adding a feature (checklist = the Scope of every "add X" issue)

- flag? → `Sources/SLCore/Flags.swift` table entry → `RunSpec` field →
  consumer in `TrainScene`/`sl` → checks file → README flag row → `sl.1`
- model/particle/system? → new file in `Sources/TrainScene/` behind the
  `Renderer` protocol → checks → register in `Sources/slChecks/Registry.swift`
- windowing change? → `Sources/OverlayKit/` → shot lane verification

## Hot files (touched by many features — neutralized)

- `Sources/slChecks/Registry.swift` — every feature appends its check
  list; carries `merge=union` in `.gitattributes`.
- `docs/ARCHITECTURE.md` — generated by `scripts/arch-graph`; regenerate
  (`scripts/arch-graph`) and commit instead of hand-editing.
- `Package.swift` — target additions only; sources are path-included so
  new files never touch it.
- `README.md` flag table — one row per flag; append, don't rewrite.

## Machine budget

- Gate concurrency: **4** (`scripts/gate` takes one of 4 `lockf` slot
  locks under the main checkout's `.hackathon/`; load average was
  already ~16 at launch).
- One screenshot at a time (`shot.lock` inside `scripts/shot`).
- Shared SwiftPM scratch: `scripts/gate` builds into
  `.hackathon/swiftpm-scratch` so worktrees share compiled deps.
- Worktrees removed on worker exit; disk ceiling — check `df -h` each
  tick.

## Permission bundle

- `.devin/config.json` — every command a worker runs, as an exact
  `Exec(…)` prefix (see the file). A denied command surfaces as
  `blocked(permission: …)`; the fix is one line there, never a
  workaround in the worker.
- Build, test and screenshot are reached **only** through
  `scripts/gate` and `scripts/shot` — no direct `swift`/`screencapture`
  entry; the bundle denies them by name.

## Verification lanes

| Scenario | Lane |
|---|---|
| Pure logic (flags, trajectory, timing) | `slChecks` spec-sentence checks |
| Overlay/window visibility | `scripts/shot` → read the PNG |
| Binary contract (`-v`, bad flag, exit codes) | gate smoke step |

## Dependency grain (one line per major library)

- AppKit/NSWindow: grain — AppKit predates iOS and compositing-era
  design; with it — NSWindow levels/collectionBehavior as documented,
  `.accessory` policy for UI-less agents; against it — relying on
  activation/focus, NSPanel conveniences, `.prohibited` default;
  era rings — `.screenSaver` raw value 1000 is spec (Apple DTS),
  `fullScreenAuxiliary` vs `fullScreenPrimary` nuance is era-specific —
  verify on macOS 27.
- SceneKit: grain — scene-graph convenience over rendering purity;
  with it — primitives, SCNScene(url:), SCNAction/SCNTransaction,
  particle systems; against it — custom shaders, expecting long-term
  API investment (deprecated since 26 SDK, maintenance only);
  era rings — `SCNView` transparency on Metal historically flaky
  (premultiplied-alpha trap) — treat "transparent background" as
  spike-verified, not assumed.
- swift-argument-parser: grain — declarative spec == docs == parser;
  with it — `@Option`/`@Flag`, `--help` for free; against it —
  single-dash legacy spellings like `-a` (needs `@Flag(name:)` with
  custom parsing or manual argv pre-scan — the classic `sl` flag style
  may need a thin manual layer; era rings — none.
- AVFoundation/NSSound: grain — fire-and-forget playback;
  with it — NSSound for one-shots, AVAudioPlayer for loops;
  against it — AVAudioEngine ceremony for a whistle.

## UI check

- `scripts/shot docs/shots/<name>.png` — freezes the run mid-frame,
  `screencapture -x` to the path. Read the image: train visible over
  desktop/windows, transparent edges, no opaque backing, cars coupled,
  smoke present. Also capture at the freeze points the contract names.

## Off-limits

- No `xcodebuild`/`xcrun`/`.xcassets`/XCTest/swift-testing — CLT-only is
  an invariant.
- No `brew install` inside any task (Xcode-license-blocked anyway;
  name-shadowing hazard).
- No network calls at runtime; no telemetry; no writes outside temp.
- Never touch `scripts/gate`, `scripts/shot`, `.devin/`, `.github/` from
  a worktree (denied in the bundle — these are the control plane).
- No force push, no `--admin` merge, no `git checkout`/`switch` in the
  shared root.
